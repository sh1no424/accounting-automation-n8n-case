| ID | Требование |
| --------- | --- |
| BR-001 | Каждый документ должен быть направлен только в одну целевую базу 1С. |
| BR-002 | Для документов из почты база 1С определяется по пометке в теме письма. Если пометка отсутствует или найдены несколько баз, документ не обрабатывается автоматически. |
| BR-003 | Из СБИС обрабатываются только входящие документы и несистемные вложения, относящиеся к первичной документации. |
| BR-004 | Поддерживаются документы в форматах XML, PDF и изображений. XML обрабатывается парсером, PDF и изображения — сервисом распознавания.|
| BR-005 | Независимо от источника и формата данные документа должны приводиться к единой внутренней модели УПД. |
| BR-006 | Документ должен содержать номер, дату, поставщика, покупателя, суммы и хотя бы одну товарную или сервисную строку. |
| BR-007 | Сумма без НДС плюс сумма НДС должна соответствовать итоговой сумме. Допустимое отклонение — не более одной копейки. |
| BR-008 | Перед созданием документа должны быть однозначно определены организация, контрагент и договор в 1С. |
| BR-009 | Документ с уже обработанным идентификатором или совпадающими ключевыми реквизитами не должен повторно создаваться в 1С. |
| BR-010 | Номенклатура сначала ищется в справочнике 1С. Если найдено несколько подходящих вариантов, документ передаётся на ручную проверку. |
| BR-011 | Документ создаётся в 1С только после успешного прохождения обязательных проверок. |
| BR-012 | При бизнес-ошибке документ передаётся бухгалтеру с указанием причины. При технической ошибке система выполняет повторные попытки, после чего уведомляет главного бухгалтера. |
| BR-013 | Техническая недоступность 1С, СБИС или сервиса распознавания не означает, что исходный документ некорректен. |
